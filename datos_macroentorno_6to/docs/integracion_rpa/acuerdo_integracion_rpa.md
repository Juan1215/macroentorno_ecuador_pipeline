# Acuerdo de integración con RPA

## Carpeta de recepción

```text
data/raw/rpa_inbox/
```

## Formato de nombres

```text
fuente_aaaammdd.extension
```

## Responsabilidades

| Equipo | Responsabilidad |
|---|---|
| RPA | Depositar archivos con nombre y formato acordado. |
| Datos | Detectar archivos nuevos y ejecutar el pipeline. |

## Evidencia de integración

- Archivo recibido.
- Log de procesamiento.
- Tablas Silver actualizadas.
- Dashboard actualizado.
